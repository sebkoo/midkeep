# Driving prompts

Each file here is the lab record for one unit of work: what was asked, what was
predicted before the run, what was observed, and what the run turned out to
disprove. They are historical and are never re-run — a prompt file describes a
session that already happened, and editing one to match later reality would
destroy the only thing it preserves.

Predictions are written before the work they predict and are not edited
afterwards; Results marks each one confirmed or falsified with the command and
output that decided it. Falsified is append-only and takes what the run
disproved that nobody predicted.

Numbering follows the unit: `01-repository-and-harness.md` is the first, and
`scripts/status.sh` counts these files to report how many units have landed.

A pattern that turns out to be reusable graduates to `.claude/skills/`. A
prompt file is not the place to keep something you intend to run again.
